# 宠物素材制作指南（用 AI 生成连贯帧）

桌宠的动画连不连贯、细节够不够，**取决于素材帧**。本指南教你：用你家宠物的照片，让 AI 生成一套**风格统一、背景透明、可循环**的精灵帧，丢进 `assets/cat/` 就能用。

---

## 一、程序需要哪些动作（动画集）

每个动作是一组连续帧。程序按状态自动切换；**没有的动作会自动回退**到相近的（比如没有 `angry` 就用 `walk`），所以你可以先做核心几个，后面再补。

| 动作集 | 何时播放 | 建议帧数 | 必需? | 说明 |
|--------|---------|---------|-------|------|
| `rest` | 静止超时后趴下休息 | 8–16 | ★必需 | 躺着呼吸/眨眼，能首尾相接循环 |
| `walk` | 移动靠近鼠标 | 8–16 | ★必需 | 一个完整步态循环，**原地走**（身体大小不变） |
| `stand`| 到达鼠标旁、警觉站立 | 4–8 | 推荐 | 站立轻微呼吸；没有就用 walk 定帧 |
| `run`  | 距离很远时快跑 | 8–12 | 可选 | 没有就用 walk 加速 |
| `angry`| 被摔下后生气 | 6–10 | 可选 | 炸毛/跺脚；没有就用 walk + 程序化怒气符号 |
| `poop` | 蹲下拉屎 | 6–10 | 可选 | 蹲姿用力；没有就用站立定帧 + 程序化汗滴 |

> 最小可用：先做 `rest` + `walk` 两套，体验就完整了。

---

## 二、硬性素材要求（不满足会闪烁/抖动/糊）

1. **透明背景**：PNG 带 alpha 通道，只有宠物、无背景、无地板、无手、无玩具。
2. **同一只宠物**：所有帧必须是同一只猫/狗，毛色花纹一致（用你的真实照片作参考图喂给 AI）。
3. **同一视角**：整套用同一机位（推荐**侧面**或 **3/4 俯视**；侧面最适合"走来走去"）。
4. **尺寸/锚点一致**：同一动作集内每帧画布尺寸相同；宠物**脚底贴画布底部、水平居中**，这样不会跳。
5. **可循环**：`walk`/`rest` 的最后一帧要能接回第一帧（首尾衔接）。
6. **分辨率**：建议高度 256–400px，画布留少量边距；程序会缩放，别太小。
7. **帧序命名**：`<动作>_<两位序号>.png`，从 `00` 起。例：`walk_00.png … walk_13.png`。

---

## 三、喂给 AI 的提示词模板

> 把下面方括号内容换成你的实际情况，连同**你家宠物的清晰照片**一起发给图像/视频生成 AI（支持参考图的模型效果最好）。

```
参考图是我家宠物：[一只白底橘斑的短毛猫]。
请以这只宠物为主角，生成一套【行走 walk】动画的连续帧精灵图，要求：
- 侧面视角，宠物在原地行走（身体大小和位置不变，只有四肢摆动）；
- 一个完整步态循环，共 12 帧，首尾可无缝衔接；
- 纯透明背景，只有宠物本体，没有地面、影子、手或任何道具；
- 每帧画布尺寸一致，宠物脚底对齐画布底部、水平居中；
- 毛色花纹与参考图严格一致，卡通描边/手绘风格统一；
- 输出为带透明通道的 PNG 序列帧。
```

换动作时把【行走 walk】替换为：
- 【休息 rest】：宠物侧躺，缓慢呼吸、偶尔眨眼，8–12 帧循环。
- 【站立 stand】：站立警觉、轻微呼吸，6 帧循环。
- 【生气 angry】：炸毛、耳朵后压、尾巴竖起抖动，8 帧。
- 【拉屎 poop】：蹲下、身体微微用力，8 帧。

> 提示：很多 AI 一次难以保证 12 帧完全一致。可以让它**先生成关键 2–3 帧**确认风格，再要求"保持同一角色补全中间帧"。或用支持"角色一致性 / 参考图"的工具（如带 reference 的图像模型、或可控的视频模型逐帧导出）。

---

## 四、把帧导入程序

1. 把每套动作的透明 PNG 按命名放进 `assets/cat/`：
   ```
   assets/cat/walk_00.png … walk_11.png
   assets/cat/rest_00.png … rest_09.png
   ```
   （可保留现有的 `idle_*.png` 作为 rest 的回退，或删掉换成 `rest_*`。）

2. 自动生成清单：
   ```
   node tools/make-manifest.js
   ```
   它会扫描所有 `<动作>_<序号>.png`，写好 `manifest.json`。

3. 重启程序：`npm start`，即可看到新素材。

> 若帧带背景需要抠图，可复用现成流程：`node tools/01-remove-bg.js <输入帧目录> <输出目录>`。

---

## 五、命名速查

| 文件名样例 | 含义 |
|-----------|------|
| `walk_00.png` ~ `walk_11.png` | 行走，12 帧 |
| `rest_00.png` ~ `rest_09.png` | 休息躺下，10 帧 |
| `stand_00.png` ~ `stand_05.png` | 站立，6 帧 |
| `angry_00.png` … / `eat_00.png` … | 生气 / 吃，可选 |

帧率在 `tools/make-manifest.js` 的 `FPS` 表里按动作设置，想更快/更慢改那里再重跑即可。
